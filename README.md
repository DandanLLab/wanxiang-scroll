# 万象绘卷（Wanxiang Scroll）

> AI 驱动的沉浸式互动叙事 / 异世界人生模拟技能 · 当前版本 **v3.1.0**

## 项目简介

万象绘卷是一个运行在 DSH 技能体系内的长篇互动叙事引擎，支持：

- **回合制异世界人生模拟**：玩家以第一人称进入原创世界，AI 扮演世界与全部 NPC
- **56 种文风即时切换**：从轻松日常到史诗战争，文风一键切换
- **剧情管理**：章节化剧情推进、伏笔登记、事件帧存档（每回合 = 一帧）
- **人生模拟**：技能成长、关系网、声望系统、多线结局
- **Apex 创作引擎**：拆书融合创作、长篇流水线（大纲 → 知识库 → 章节 → 一致性校验）
- **纯指令版 dsv4**：纯指令驱动，无需复杂配置

## 目录结构

```
wanxiang-scroll/
├── SKILL.md          # 技能主文件（给 agent 读的使用说明）
├── VERSION           # 版本号（3.1.0）
├── stories/          # 故事存档（玩家进度）
├── saves/            # 快速存档位
├── scripts/          # 辅助脚本
├── data/             # 世界观数据
├── novel_data/       # 小说粮仓（拆书素材）
├── references/       # 参考文档（章节化：核心系统/剧情管理/人生模拟等）
└── .clawhub/         # 技能市场元数据
```

## 快速开始

将本目录放置于 DSH 技能目录（`skills/wanxiang-scroll`），agent 会自动发现。
对话中唤醒词与指令见 `SKILL.md`。
