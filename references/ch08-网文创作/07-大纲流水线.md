# 大纲流水线（可执行四件套）

> 2026-09-16 融合进版：把"大纲怎么写"从参考资料升级成可执行流水线。
> 四个独立技能已装进 `skills/`，这里只讲怎么接。

## 流水线四步

```
脑洞
 │
 ▼
① novel-outline-architect   出大纲蓝图（一句话卖点/主辅爽点/核心循环六步/世界层级/人物功能映射/主角六问/反派阶梯/分卷七要素）
 │
 ▼
② novel-kb-builder          蓝图拆成原子化知识库（人物/地点/设定/伏笔各自立卡，scripts/init_kb.py 可初始化目录）
 │
 ▼
③ novel-chapter-writer      按分卷大纲逐章生成（scene-template + chapter-checklist）
 │
 ▼
④ novel-continuity-guardian 一致性守卫（时间线/人物状态/设定/伏笔回收，report-template 出校验报告）
 │
 ▼
成稿 → 回到 ch07 质量控制过禁令和评分表
```

## 为什么这么排

- **①是发动机**：长篇网文不是讲完一个故事，是找到一个能让读者上瘾的核心爽点模式反复演绎。先造发动机再造车身。
- **②是防崩关键**：设定不原子化，写到20万字必出现"主角左眼是什么颜色"级别的自相矛盾。
- **④是长篇保险丝**：每卷跑一次校验，伏笔忘回收、时间线打架当场抓，不等到读者抓。
