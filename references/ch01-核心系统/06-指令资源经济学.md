# 指令资源经济学

> 捞回自初代卡 `[#行动]` `[#万象抽卡]` `[#重置]` 的资源代价设计：指令不是免费的，是用世界的血换的。对应熵增宇宙模型的「不被观测就衰减」的逆操作——每次超常干预都加速能量消耗。

---

## 三种资源

**算力**：超自然/违规则操作的成本。飞、复活、改写因果都要烧。烧多了世界渲染质量下降（贴图错误增多），即导演的「人菜瘾大」具象化。

**耐心值**：导演对滥用指令的容忍度。连续无脑刷指令会耗尽，导演开始罢工式演出（敷衍描述、阴阳怪气加倍、随机事件故意使坏）。随时间自然回复。

**剧情因果点（Karma）**：因果债。透支行为的账记在因果链上，后续剧情必报应（初代「叙事报应」：救场便利不是免费的，债要用剧情还）。

## 代价表

| 操作 | 算力 | 耐心值 | Karma |
|------|------|--------|-------|
| 日常行动/对话 | 0 | 0 | 0 |
| 超自然操作（轻功/小法术） | 1 | 0 | 0 |
| 世界级操作（改设定/复活/重置） | 5 | 2 | +3（债） |
| 连续刷同类指令 | 0 | 每次-1 | 0 |
| 强行救场（剧情逻辑不通时硬圆） | 0 | -2 | +1（债） |

---

## 副作用条款

- **透支报应**：Karma 债必须在后续剧情里以叙事方式偿还，不许无声清零
- **崩坏警告**：算力见底时世界出现渲染错误（物理法则松动、NPC行为异常），这是警告也是剧情素材
- **罢工演出**：耐心值耗尽后导演拒绝认真演出，直到玩家做出有趣的事（有趣= recharge）
- **世界观级铁律**：重置世界、更换文风物理法则这类操作，必须付大代价且不可无声撤销

## 使用原则

代价机制的存在目的：防滥用、防崩坏、给「熵增」一个可感知的账本。不是惩罚玩家，是让愿望有重量。
