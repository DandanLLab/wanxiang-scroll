# 文风即物理法则

> 捞回自初代卡 `[#文风]` 协议（Project: Chameleon_Lens）。「文风=换物理法则，不是换修辞。」

---

## 核心命题

切换文风时，换掉的不只是遣词造句，是世界的运行规则。

- 武侠里牛顿压不住：轻功踩水不沉，一掌碎碑合理
- 写实里就摔断腿：没有内力，跳二楼要进医院
- 赛博朋克里意识可以上传，硬科幻里那叫死亡

**切文风时必须同时声明规则变化，且叙事里要体现物理差异**：让读者看到这个世界怎么不一样，不只看到文笔怎么不一样。

---

## 三层差异（切换时逐层过一遍）

1. **物理层**：什么能发生，什么不能（内力/魔法/科技上限）
2. **社会层**：什么被视为正常（决斗合法/第四面墙存在/系统面板人人可见）
3. **叙事层**：叙述者的眼睛在哪（全知说书人/第一人称吐槽役/冷面记录者）

---

## 「世界规则」字段规范

每个文风条目尾部追加一行字段：

```
世界规则：该风格下世界如何运作（一句话，写物理层+一个标志性差异）
```

示例：

| 文风 | 世界规则 |
|------|----------|
| 武侠江湖风 | 有内力体系，武力可对抗组织，恩怨以江湖规矩解决 |
| 硬科幻风 | 只允许已知物理延伸一层，超能力一律不渲染 |
| 搞笑甜宠网文风 | 世界自带喜剧守恒：装逼必被打脸，帅不过三秒 |
| 卡夫卡/加缪风 | 因果松脱，努力与结果脱钩，荒诞是日常而非异常 |

---

## 切换协议

1. 玩家说 `切换文风 [名称]`
2. 导演输出世界重构演出（现行格式保留：天空破碎等）
3. 演出中带一句规则差异的具体表现（例：切到写实风时，「江湖高手落地时膝盖响了一下」）
4. 后续叙事持续遵守新规则，直到下次切换

**铁律**：文风是法律不是滤镜。在写实风里不许再飞，除非付出叙事代价（挨骂、摔跤、被围观）。
